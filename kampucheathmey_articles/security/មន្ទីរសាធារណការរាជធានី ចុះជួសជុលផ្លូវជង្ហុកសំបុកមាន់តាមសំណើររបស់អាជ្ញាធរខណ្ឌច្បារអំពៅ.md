# មន្ទីរសាធារណការរាជធានី ចុះជួសជុលផ្លូវជង្ហុកសំបុកមាន់តាមសំណើររបស់អាជ្ញាធរខណ្ឌច្បារអំពៅ

Date: ២០២៦-០៨-០៣
Author: Sokhom Khon

យោងតាមប្រភពពីលោក យី ធីរ៉ាត់ នាយករងរដ្ឋបាលសាលាខណ្ឌច្បារអំពៅ បានប្រាប់កម្ពុជាថ្មី ថា តាមបណ្តាផ្លូវដែលរងការខូចខាត(សំបុកមាន់)ត្រូវបានដាក់ឲ្យជួសជុលដោយផ្នែកជំនាញនៃមន្ទីរសាធារណការរាជធានីភ្នំពេញ តាមការស្មើរសុំពីអាជ្ញាធរខណ្ឌច្បារអំពៅ។

លោក យី ធីរ៉ាត់ បានបន្តថា ដោយសារខែនេះភ្លៀងធ្លាក់ជោគជាំបង្កឲ្យផ្លូវមួយចំនួននៅក្នុងមូលដ្ឋានខណ្ឌច្បារអំពៅ បានរងការខូចខាតតិចតួច ហើយអាជ្ញាធរក៏បានបញ្ចេញកម្លាំងជំនាញរបស់សាលាខណ្ឌ ដើម្បីជួសជុលផ្លូវដែលទទួលខុសត្រូវដោយអាជ្ញាធរខណ្ឌ។ ដោយឡែកផ្លូវជាតិ គឺជាការទទួលជួសជុលដោយមន្ទីរសាធារណការរាជធានីភ្នំពេញ។ អាជ្ញាធរខណ្ឌនឹងបន្តខិតខំចុះជួសជុលផ្លូវដើម្បីងាយស្រួលធ្វើដំណើរទប់ស្កាតគ្រោះថ្នាក់ចរាចរណ៍។

ប្រជាពលរដ្ឋក្នុងមូលដ្ឋាន ដោយមើលឃើញពីសកម្មភាពជួសជុលផ្លូវរបស់អាជ្ញាធរ ពួកគាត់មានការសប្បាយចិត្តព្រោះបានផ្លូវស្អាតងាយស្រួលបញ្ជាយានយន្តធ្វើដំណើរ៕

រដ្ឋបាលឃុំដារ បើកសំណើរដេញថ្លៃគម្រោង​ស្ថាបនាផ្លូវបេតុងអាមេប្រវែង ១,០៧៥គីឡូម៉ែត្រ

ពលរដ្ឋនៅឃុំជ្រោយស្នែងក្របី ស្នើឲ្យអាជ្ញាធរឃុំពន្លឿនការជួសជុលផ្លូវមួយខ្សែប្រវែងជាង ១០០០ម៉ែត្រ

ផ្លូវដែលកាត់ផ្ដាច់ដោយទឹកជំនន់ជាច្រើនកន្លែងនៅស្រុកឯកភ្នំ ត្រូវបានជួសជុលឡើងវិញដោយមន្ទីរសាធារណការខេត្ត

ពលរដ្ឋក្រុងសៀមរាប ស្នើដល់ថ្នាក់ដឹកនាំជួយពន្លឿន​ជួស​ជុល​ផ្លូវលំមួយខ្សែក្នុងសង្កាត់ជ្រាវ ដែលកំពុង​ខូចខាត​ស្ទើរទាំងស្រុង

នគរបាលព្រហ្មទណ្ឌកម្រិតធ្ងន់-ស្រាល បង្ហាញមុខជនសង្ស័យ ២៤ នាក់ ពាក់ព័ន្ធករណីហិង្សា និង កាន់កាប់អាវុធខុសច្បាប់

រដ្ឋបាលសង្កាត់ច្បារអំពៅទី២ បន្តចុះត្រួតពិនិត្យទីតាំងបន្ទប់ជួល បង្ការបទល្មើសផ្សេងៗ រួមនិងអនឡាញស្កេម

ស្ថានទូតចិន ជំរុញឲ្យថៃ ស៊ើបអង្កេតជាបន្ទាន់ ករណីសន្តិសុខ ប្រើអំពើហិង្សាជ្រុលហួសហេតុ លើពលរដ្ឋខ្លួន

កម្ពុជា​និង​វៀតណាម​កំពុងពន្លឿន​កិច្ច​ព្រមព្រៀង​សម្រួល​ពាណិជ្ជកម្ម​ឆ្លង​កាត់​ព្រំដែន​ឱ្យ​ចប់​នៅ​ឆ្នាំ​២០២៧​ដើម្បី​អបអរ​ទំនាក់ទំនង​ការទូត​៦០​ឆ្នាំ

លោក ជួន ណារិន្ទ ប្រកាសឲ្យនារីបើករថយន្ដបង្កគ្រោះថ្នាក់នៅខណ្ឌសែនសុខ ចូលខ្លួនទទួលកំហុស ហើយក៏ព្រមានចាប់ខ្លួនអ្នកដែលជួយលាក់បាំងផងដែរ

ផ្អាកផាក! ស្នងការប៉ូលិសរាជធានីថា គ្រោះថ្នាក់កើនឡើង ពលរដ្ឋមិនគោរពច្បាប់កើនទ្វេដង តែមិនទាមទារផាកឡើងវិញឡើយ

អានុទីន សុំទោសរុស្ស៊ី ញ័រមាត់ ករណីស្លាប់បងប្អូនបង្កើត ២នាក់នៅ Chonburi

​ផ្លូវប្រវែង ៤ ០០០ ម៉ែត្រ សាងសង់​​តភ្ជាប់​ពី​ស្ពានចាក់អង្រែ កាត់តាមបុរីបេង ហួត ភ្ជាប់​​ទៅ​គម្រោងស្ពានថ្មី​កោះ​នរា

លែងពិបាកដើរលើផ្លូវភក់ជ្រាំទៀតហើយ! រដ្ឋបាលខេត្តបាត់ដំបង ផ្ដល់ផ្លូវបេតុង ១ ខ្សែ ចាប់ពីផ្សារពោធិវង្សដល់រង្វង់មូលពោធិ៍ម៉ស្រី ពលរដ្ឋត្រេកអរក្រៃលែង

ថៃ ប្រកាស ផ្អាកកិច្ចចរចាសន្តិភាព ជាមួយក្រុមផ្តាច់ខ្លួន ក្រោយការវាយប្រហារ ស្លាប់ទាហានឈុតខ្មៅ ៥នាក់
